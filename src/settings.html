캘린더 연동

국경일·공휴일

구글 캘린더

비공개 iCal 주소 찾는 법
  1. PC에서 구글 캘린더(calendar.google.com)를 엽니다.
  2. 왼쪽 "내 캘린더"에서 캘린더 이름 옆 ⋮ → 설정 및 공유.
  3. 아래쪽 캘린더 통합의 iCal 형식의 비공개 주소를 복사해 붙여 넣습니다.

이 주소를 아는 사람은 누구나 일정을 볼 수 있으니 다른 곳에 공유하지 마세요.

지금은 구글 일정을 불러와 보여주기만 합니다(30분마다 갱신). 이 위젯에서 입력한 일정을 구글로 보내는 양방향 동기화는 다음 단계(Firebase 연동)에서 추가합니다.

외부 캘린더 (URL)

학교·학년 캘린더, 네이버·아웃룩 등에서 제공하는 iCal(.ics) 주소를 넣으면 날짜별 일정을 불러옵니다. webcal:// 주소도 됩니다.

AI 비서

사진·문서(HWP, PDF)·녹음 파일을 위젯에 끌어다 놓거나 ✦ 버튼을 누르면, AI가 일정·할 일·마감을 찾아 캘린더에 넣습니다. 분석에는 본인의 API 키가 필요합니다(사용량만큼 요금이 청구될 수 있습니다).

Gemini 문서·사진·녹음 모두 가능 · 녹음 분석은 Gemini만 됩니다

Gemini API 키 받는 법
  1. aistudio.google.com 에 구글 계정으로 로그인합니다.
  2. 왼쪽 Get API key → API 키 만들기를 누릅니다.
  3. 만들어진 키(AIza로 시작)를 복사해 위 칸에 붙여 넣고 저장합니다.

학교 업무 문서를 보낼 때는 개인정보가 담기지 않았는지 확인하세요. 무료 등급은 입력 내용이 서비스 개선에 쓰일 수 있습니다.

Claude 문서·사진·PDF (녹음은 Gemini로 자동 전환)

모델 이름 바꾸기 (고급)

새 모델이 나오면 이름만 바꾸면 됩니다. "모델을 찾을 수 없습니다" 오류가 나면 각 회사 문서에서 현재 모델 이름을 확인하세요.

Claude Code 연결

한 번 등록해 두면 Claude Code(데스크톱 앱·터미널·VS Code)에서 "이 공문 일정 넣어줘", "다음 주 일정 알려줘"처럼 말로 캘린더를 다룰 수 있습니다. 캘린더가 실행 중이어야 합니다. (웹 버전 Claude Code는 이 PC에 접속할 수 없어 연결되지 않습니다.)

1. 등록 명령 (한 번만)

명령 프롬프트나 PowerShell에 붙여 넣고 Enter. Node.js가 설치되어 있어야 합니다(clasp를 쓰고 있다면 이미 설치되어 있습니다).

Node.js가 없을 때 (설치형 캘린더 전용)

2. 사용 예

  • "바탕화면의 10월 학사일정.hwp 읽고 우리 반 관련 일정 캘린더에 넣어줘"
  • "D:\녹음\학년협의회.m4a 들어보고 결정된 할 일 일정에 넣고 회의 요약해줘"
  • "다음 주 일정 정리해줘" · "금요일 체육대회를 다음 주 월요일로 옮겨줘"

3. 프로그램 고치기

캘린더 자체를 바꾸고 싶을 때는 소스 폴더(my-scheduler-desktop)에서 Claude Code를 열고 "설정 창에 ○○ 기능 추가해줘"처럼 요청하세요. 폴더의 CLAUDE.md에 작업 규칙이 정리되어 있고, GitHub에 올리면 설치된 캘린더가 자동으로 업데이트됩니다.
