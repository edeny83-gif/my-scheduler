# MyScheduler 바탕화면 캘린더 (PC)

## 설치
- **설치형**: `MyScheduler-Setup-0.4.x.exe` 실행 → 설치 폴더 선택 → 바탕화면 바로가기 생성.
- **포터블**: `MyScheduler-Portable-0.4.x.exe`를 원하는 폴더에 두고 실행 (설치 없이, USB로 다른 PC에서도 사용).

처음 실행하면 "Windows의 PC 보호" 파란 창이 뜰 수 있습니다. 코드 서명을 하지 않은 개인 프로그램이라 그렇습니다.
**추가 정보 → 실행**을 누르면 됩니다.

## 클라우드 동기화 (PC ↔ 폰) — 처음 한 번만 설정
Firebase 프로젝트 `my-scheduler-e7b5f`에 이미 연결되어 있습니다. 콘솔에서 아래 두 가지만 하세요.

1. **Firestore 보안 규칙 게시 (필수)**
   Firebase 콘솔 → Firestore Database → **규칙** 탭 → 기존 내용을 모두 지우고 `firestore.rules`의 내용을 붙여 넣은 뒤 **게시**.
   "로그인한 본인만 자기 일정을 읽고 쓰기"라는 규칙입니다. 게시하지 않으면 로그인해도 "권한이 없습니다" 오류가 납니다.
2. **(권장) 외부 가입 막기**
   Authentication → **설정** 탭 → **사용자 작업**에서 사용자 가입(생성) 사용 설정을 끕니다. 본인 계정을 먼저 만든 뒤에 하세요.

그다음 PC 캘린더와 폰 앱 **양쪽에서 같은 이메일/비밀번호로 로그인**하면 일정이 실시간으로 맞춰집니다.
- 위젯 제목 옆 점: 초록 = 동기화됨, 노랑 = 연결 중·오프라인, 빨강 = 오류, 회색 = 로그인 안 함 (점을 누르면 설정으로 이동)
- 인터넷이 없어도 쓸 수 있고, 연결되면 자동으로 맞춥니다. 같은 일정을 양쪽에서 고쳤다면 **더 나중에 고친 쪽**이 남습니다.
- 처음 로그인할 때 이 기기에 있던 일정은 서버로 올라가 합쳐집니다. 다른 계정으로 로그인하면 이 기기의 일정은 그 계정의 데이터로 바뀝니다.
- 일정을 지울 때는 반드시 앱에서 지우세요(서버 콘솔에서 직접 지우면 다시 살아날 수 있습니다).

## AI 비서
공문(HWP·PDF), 가정통신문 사진, 회의 녹음 등을 **위젯에 끌어다 놓거나 ✦ 버튼**을 누르면 AI가 일정·할 일·마감을 찾아 줍니다.
결과를 확인·수정하고 "추가"를 누르면 캘린더에 들어가며, 설정에서 "확인 없이 바로 추가"를 켤 수도 있습니다(되돌리기 가능).

1. 설정(⚙) → **AI 비서**에 Gemini API 키를 넣고 "연결 확인" (녹음 분석은 Gemini만 가능). Claude 키도 쓸 수 있습니다.
2. "나에 대한 설명"에 예: `초등학교 3학년 담임`을 적으면 관련 일정을 더 잘 골라냅니다.

## Claude Code 연결
설정 → **Claude Code 연결**의 명령을 한 번 붙여 넣으면, Claude Code(PC용)에서
"이 공문 일정 넣어줘", "녹음 듣고 할 일 정리해서 캘린더에 넣어줘", "다음 주 일정 알려줘"처럼 말로 캘린더를 다룰 수 있습니다.
캘린더가 켜져 있어야 하며, 추가되면 Windows 알림으로 알려 줍니다.

## 사용법
- 위치 이동: 위젯 맨 위(년·월 줄)를 끌기
- 크기 조절: 위젯 가장자리나 모서리를 끌기 / 설정 → "바탕화면 전체 크기로"
- 일정 추가: 날짜를 두 번 클릭, 또는 ＋
- 일정 수정·삭제: 일정 글자를 클릭
- 달 이동: ‹ › 버튼 또는 달력 위에서 마우스 휠
- 설정: ⚙ 또는 작업표시줄 오른쪽 트레이 아이콘 우클릭
- 위젯이 안 보이면: 바로가기를 다시 누르거나 트레이 아이콘(작업표시줄 오른쪽 ^ 안에 숨어 있을 수 있음)을 클릭 → 위젯이 잠깐 맨 앞으로 나옵니다. 잠금 해제·위치 초기화도 트레이 메뉴에 있습니다.
- 화면 처리기가 죽는 PC(보안 프로그램 등)에서는 프로그램이 스스로 설정을 낮춰 자동으로 다시 시작합니다(최대 3단계). 한 번 정해지면 유지되며, 처음 상태로 되돌리려면 데이터 폴더의 `safe-mode.json`을 지우세요.
- 실행이 안 될 때: `%APPDATA%\my-scheduler-desktop\startup.log` 파일 내용을 확인하세요(오류가 나면 창으로도 알려 줍니다).

일정과 설정은 `%APPDATA%\my-scheduler-desktop\` 에 저장됩니다(트레이 → 데이터 폴더 열기). `events.json.bak`은 직전 백업입니다.

## 개발
```
npm install
npm start          # 실행
npm run dist       # exe 만들기 (Windows에서)
node test/feeds.test.js
```
Claude Code로 수정할 때는 `CLAUDE.md`를 먼저 읽게 하세요.

- 개발자가 PR을 병합하면 GitHub가 새 설치 파일을 만들어 Releases에 올립니다.
- **설치형(Setup)** 으로 설치한 앱은 켠 뒤 10초 후와 3시간마다 확인하고, 새 버전을 받으면 알림이 뜹니다. 알림을 누르면 바로 다시 시작해 적용하고, 그냥 두면 앱을 끌 때 설치됩니다.
